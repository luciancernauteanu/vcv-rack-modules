# vcv-rack-plugins

A collection of plugins for [VCV Rack](https://vcvrack.com/), the open-source modular synthesizer.

## Getting started

1. Install [VCV Rack 2](https://vcvrack.com/Rack) and the Rack SDK.
2. Clone this repository.
3. Build the plugins against the SDK, following the instructions for each plugin.
